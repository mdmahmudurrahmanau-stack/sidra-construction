SIDRA CONSTRUCTION WEBSITE

1. Open index.html and replace:
   - Phone number
   - Email address
   - WhatsApp number
   - Project information
   - Company address

2. In the quote form, replace:
   YOUR-EMAIL@example.com
   with the email where you want to receive quote requests.

3. Upload index.html and styles.css to Cloudflare Pages.

Cloudflare Pages:
- Create a new Pages project
- Choose Direct Upload
- Upload the ZIP or both files
- Deploy
